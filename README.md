# ごち印帖

行ったお店・行きたいお店を Googleマップのリンクから登録し、累計訪問回数を記録する個人用ログアプリ。
Google Apps Script + Google スプレッドシートで動くので、Googleアカウントだけあれば無料で、パソコンでも iPhone でも同じデータを使えます（APIキーや課金登録は不要）。

- `Code.gs` … サーバー側（スプレッドシートへの保存、Googleマップ共有リンクの解析）
- `index.html` … 画面

## セットアップ（最初の1回・約5分）

1. パソコンで <https://sheets.new> を開き、新しいスプレッドシートを作る（名前は「ごち印帖」など）。
2. メニューの **拡張機能 → Apps Script** を開く。
3. 最初からある `コード.gs` の中身を全部消して、このフォルダの `Code.gs` の中身を貼り付ける。
4. 左の「ファイル」の **＋ → HTML** を選び、名前を `index` にする（`index.html` になる）。中身を全部消して、このフォルダの `index.html` の中身を貼り付ける。
5. 💾 で保存し、右上の **デプロイ → 新しいデプロイ**。
   - 種類の選択（歯車）: **ウェブアプリ**
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
6. 「アクセスを承認」を求められたら自分のアカウントを選ぶ。「このアプリは Google で確認されていません」と出たら **詳細 → （プロジェクト名）に移動** で進む（自分で作ったスクリプトなので出る表示です）。
7. 表示された **ウェブアプリのURL**（`https://script.google.com/macros/s/…/exec`）がアプリのURLです。
   - パソコン: ブックマークに登録
   - iPhone: Safari で開いて 共有 → **ホーム画面に追加**

> アクセスを「全員」にすると、URLを知っている人は誰でも開けます。URLは推測できない長い文字列ですが、他人には教えないでください。
> 「自分のみ」にすることもできますが、ブラウザで複数の Google アカウントにログインしていると開けないことがあります。

コードを更新したときは **デプロイ → デプロイを管理 → 鉛筆 → バージョン: 新バージョン → デプロイ** で同じURLのまま反映されます。

## 画面を GitHub Pages に置く（「Google Apps Script のユーザーによって作成…」の表示を消す）

Apps Script のURLを直接開くと Google の注意書きバナーが出ます。画面（`index.html` と `icon.png`）を GitHub Pages に置き、Apps Script は保存先としてだけ使うと出なくなります。

1. このリポジトリを GitHub Pages で公開する。
2. 使う端末ごとに1回だけ、設定用リンク `https://<ユーザー名>.github.io/<リポジトリ名>/#api=<URLエンコードしたウェブアプリのURL>` を開く
   （または「統計・設定」タブの「データ保存先の設定」にウェブアプリのURLを貼る）。
3. 設定済みの端末では「統計・設定」タブの「ほかの端末で使う」に設定用リンクが表示される。

ウェブアプリのURLはデータを読み書きできる鍵なので、リポジトリには書かないこと（端末のブラウザにだけ保存されます）。

## Googleマップからワンタップ登録

アプリの「統計・設定」タブに、自分のURL入りの手順とコピー用の文字列が表示されます。

- **iPhone**: 「ショートカット」アプリで「ごち印帖に追加」を1回作る
  （共有シートに表示 → URLエンコード → URLを開く `アプリのURL?add=エンコード済みテキスト`）。
  以後は Googleマップで 共有 → ごち印帖に追加 → 「行った！」か「行きたい」をタップ。
- **パソコン**: ブックマークレットを登録し、Googleマップでお店を開いてクリック。
- どちらも使わない場合は、アプリの「＋ 登録」に共有リンクを貼り付ければ店名が自動入力されます。

登録済みのお店をもう一度共有した場合は、新規登録ではなく来店回数が +1 されます。
2回目以降の来店は、リストの **＋行った** をタップするだけです。

## 機能

- 行った / 行きたい の2段階管理（行きたい店に来店すると自動で「行った」に移動）
- ワンタップで来店記録、累計訪問回数・最終訪問日・来店履歴（日付をさかのぼって追加可、ひとことメモ付き）
- ジャンル・タグ・5段階評価・メモ
- 検索、絞り込み、並べ替え（最近行った順 / 訪問回数順 / 現在地から近い順 / 評価順 など）
- マップ表示（訪問回数が多いほどピンが大きい）、Googleマップで開く・経路
- 統計（訪問回数ランキング、月別・ジャンル別の訪問回数）、行きたい店ルーレット
- データは自分のスプレッドシート（`places` / `visits` シート）に残るので、バックアップや一括編集は Sheets でそのまま可能

## ローカルで試す

`index.html` をブラウザで開くと「お試しモード」で動きます（その端末のブラウザにだけ保存、短縮リンクの解析は不可）。
